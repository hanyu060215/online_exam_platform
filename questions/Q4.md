# Python Variable Scope

## Description
Consider the following Python code:

```python
x = 10

def modify_x():
    x = 20
    print(x)

modify_x()
print(x)
```

What is the correct description of how global variables work in Python functions?

## Type
multiple_choice

## Choices
- Global variables can be directly accessed and modified inside functions
- Global variables can be accessed inside functions, but require the 'global' keyword to be modified
- Global variables cannot be accessed or modified inside functions
- Global variables can only be used in the main program, not in functions at all

## Notes
- This question tests understanding of Python's variable scope rules
- Consider both reading and writing to global variables
- Think about the LEGB (Local, Enclosing, Global, Built-in) rule in Python
