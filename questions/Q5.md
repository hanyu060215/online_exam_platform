# Explain Time Complexity

## Type
short_answer

## Description
In computer science, time complexity is a measure of the amount of time an algorithm takes to run as a function of the length of the input. It's typically expressed using Big O notation.

Explain the time complexity of the following Python code snippet and justify your answer:

```python
def find_max_min(arr):
    if not arr:
        return None, None
    
    max_val = min_val = arr[0]
    
    for num in arr:
        if num > max_val:
            max_val = num
        if num < min_val:
            min_val = num
    
    return max_val, min_val
```

Your answer should include:
1. The Big O notation for this function
2. An explanation of why this is the correct time complexity
3. A brief discussion of whether this is optimal or if it could be improved

## Notes
- Focus on the dominant operations in the code
- Consider both best-case and worst-case scenarios
- Be specific about which parts of the code contribute to the overall time complexity
